# MY MONEY — 개인 가계부 · 자산관리 PWA

아이폰 홈 화면에 설치해 앱처럼 쓰는 개인 가계부입니다. 서버·회원가입 없이 **모든 데이터는 내 기기(IndexedDB)에만** 저장됩니다.

## 주요 기능

| 메뉴 | 기능 |
|---|---|
| **HOME** | 순자산(총자산−총부채), 지난달(또는 기준일) 대비 증감, 이번 달 수입·지출·저축액·저축률·남은 예산, 카테고리 도넛 차트, 주간 예산 진행률, 최근 거래 |
| **HISTORY** | 월별 거래 내역, 유형 필터(지출/수입/이체/상환/조정), 전체 기간 검색, 수정·삭제, CSV 내보내기 |
| **+** | 지출·수입·이체·대출 상환 입력(금액 빠른 버튼, 오늘/어제), **캡처 이미지 자동 기록(OCR)** |
| **ASSETS** | 자산 계정(현금·입출금·적금·예금·주식·기타), 잔액 맞추기, 대출(금리·월 상환·상환방식·예상 완납일), 자산/부채/순자산/누적상환 추이 그래프(1개월~전체) |
| **GOALS** | 기간별(최단기·단기·중장기·장기) 목표, 순자산/저축/직접입력 목표, 달성률·남은 금액·월평균 필요액, 목표 경로 그래프, **미래 자산 시뮬레이션**(1·3·5·10년, 목표 달성 시점) |
| **설정(⚙︎)** | 연봉·식대·실수령액·저축 목표, 월/주간 예산·주 시작 요일, 카테고리·결제수단 편집, 라이트/다크, JSON 백업·복원, CSV, OCR 엔진, 전체 삭제 |

### 계산 원칙
- **순자산 = 총자산 − 총부채.** 첫 실행 시 보유 현금 1억 500만 원 − 학자금대출 6,000만 원 = **4,500만 원**으로 시작합니다(모두 수정 가능).
- **기준일 잔액**: 계정·대출은 입력한 기준일의 잔액에서 출발하며, 이후 기록한 거래만 잔액에 더해집니다. 기준일 이전 거래는 통계에는 포함되지만 잔액에는 다시 더해지지 않아 **중복 합산이 없습니다.**
- **이체**는 수입·지출이 아닙니다(순자산 불변).
- **대출 상환**은 원금과 이자로 나눠 기록합니다. 원금은 부채를 줄이고(지출 아님), 이자만 지출(‘대출 이자’)로 집계됩니다. 금리·월 상환액 기준 자동 계산 버튼 제공.
- **저축액 = 수입 − 지출**, 저축률 = 저축액 ÷ 수입.
- **순자산 목표**는 현재 순자산과 자동 연동, **저축 목표**는 선택한 저축 계정 잔액 합계(부채 미반영)로 측정합니다.
- 시뮬레이션은 가정에 따른 예측이며 확정 금액이 아닙니다. 연봉 상승분 반영 시 세금·공제율과 생활비 증가율을 따로 설정합니다.

### 캡처 이미지 자동 기록 (OCR)
- 카드 결제내역·은행 거래내역·영수증 캡처를 올리면 날짜·시간·금액·가맹점·수입/지출·카테고리를 추출하고, 여러 거래는 각각 분리합니다.
- **기기 내 처리**(Tesseract.js, 한국어+영어). 이미지가 외부 서버로 전송되지 않고, 외부 OCR API·API 키를 쓰지 않습니다.
- 인식 결과는 **확인 화면**에서 수정 후 저장합니다. 이미 등록된 거래와 같은 날짜·금액·거래처면 ‘중복 가능’으로 표시하고 기본 선택을 해제합니다.
- 실패하거나 결과가 이상하면 **수동 입력으로 전환**(인식값 이어받기).
- 엔진(약 9MB)은 첫 사용 때 한 번 받아 기기에 저장되며, 이후 **오프라인에서도 동작**합니다. 화면에 온라인/오프라인·설치 상태가 표시됩니다.
- 다크모드 캡처는 자동 반전 처리합니다. 같은 가맹점의 카테고리를 수정해 저장하면 다음부터 그 카테고리로 추정합니다.

## 아이폰 설치 방법

1. 아래 **무료 배포** 방법으로 HTTPS 주소를 만듭니다. (예: `https://내아이디.github.io/MY-MONEY/`)
2. 아이폰 **Safari**에서 그 주소를 엽니다. (크롬 등 다른 브라우저 X)
3. 하단 **공유 버튼(□↑)** → **‘홈 화면에 추가’** → 이름 `MY MONEY` 확인 → **추가**.
4. 홈 화면의 MY MONEY 아이콘으로 실행하면 주소창 없이 전체 화면 앱으로 열립니다.
5. 첫 화면에서 기준 잔액·대출·연봉 등을 확인하고 **시작하기**.
6. 설정(⚙︎) → **기기 내 OCR 엔진 → 받기**를 Wi-Fi에서 한 번 눌러 두면 이후 오프라인에서도 캡처 인식이 됩니다.

> ⚠️ Safari 탭에서 쓰던 데이터와 홈 화면 앱의 데이터는 **서로 별개 저장소**입니다. 처음부터 홈 화면 앱으로 사용하세요. 옮겨야 하면 JSON 백업 → 복원을 이용합니다.

### 설치 후 확인 (실기기 체크리스트)
- [ ] 홈 화면 아이콘 실행 시 주소창 없이 전체 화면
- [ ] 하단 탭바가 홈 인디케이터와 겹치지 않음
- [ ] 거래 1건 입력 → 앱 완전 종료 후 재실행해도 유지
- [ ] 비행기 모드에서 실행·조회·수동 입력 가능
- [ ] 캡처 1장 인식 → 확인 화면 → 저장
- [ ] 설정 → 전체 백업 → ‘파일에 저장’으로 iCloud Drive에 저장됨

## 무료 HTTPS 배포

### 방법 A. GitHub Pages (추천)
1. https://github.com 가입 → 우측 상단 **+ → New repository** → 이름 `MY-MONEY`, **Public** → Create.
2. 저장소 화면의 **uploading an existing file** 클릭 → 압축을 푼 `MY-MONEY` 폴더 **안의 모든 파일·폴더**를 드래그 → **Commit changes**.
   (최상단에 `index.html`이 보여야 합니다.)
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
4. 1~2분 후 `https://<아이디>.github.io/MY-MONEY/` 에서 열립니다.

> 저장소가 Public이어도 **내 가계부 데이터는 올라가지 않습니다**(앱 코드만 공개, 데이터는 각 기기에만 저장).

### 방법 B. Cloudflare Pages
1. https://dash.cloudflare.com 가입 → **Workers & Pages → Create → Pages → Upload assets**.
2. 프로젝트 이름 입력(예: `my-money`) → `MY-MONEY` 폴더 업로드 → **Deploy**.
3. `https://my-money.pages.dev` 주소로 접속합니다. (`_headers` 파일이 서비스워커 캐시 설정을 처리합니다.)

### 앱 업데이트 배포
코드 수정 후 `service-worker.js`의 `VERSION` 값을 올려(예: `1.0.0` → `1.0.1`) 다시 업로드합니다. 앱을 열면 상단에 **‘새 버전이 준비되었습니다 → 업데이트’**가 뜨며, **기존 데이터(IndexedDB)는 그대로 유지**됩니다.

## 데이터 보관 · 백업
- 저장: 기기 브라우저의 IndexedDB (외부 전송 없음, 입력 즉시 자동 저장, 저장 실패 시 오류 안내)
- 브라우저 저장소는 영구 보관이 보장되지 않습니다. **홈 화면에 백업 알림**(미백업 또는 14일 경과)이 표시됩니다.
- **JSON 전체 백업**: 계정·거래·대출·목표·설정 전부 → 복원에 사용 (아이폰은 공유 시트 → ‘파일에 저장’)
- **CSV 내보내기**: 거래내역 분석용(엑셀 한글 깨짐 방지 BOM 포함)
- 삭제는 모두 확인 단계를 거치며, 전체 삭제는 2단계 확인입니다.

## 폴더 구조
```
MY-MONEY/
├── index.html              앱 화면 골격 · iOS 메타태그
├── style.css               디자인(라이트/다크, Safe Area)
├── app.js                  전체 로직(데이터·계산·화면·OCR·백업)

├── _headers, .nojekyll     Cloudflare/GitHub Pages 설정
├── tests/                  자동 테스트 스크립트 · 샘플 캡처
├── TEST_RESULTS.md         테스트 결과
└── README.md
```

## 로컬에서 실행
```bash
cd MY-MONEY
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
(파일을 더블클릭해 `file://`로 열면 서비스워커·OCR이 동작하지 않습니다.)

## 알려진 제약
- OCR 정확도는 캡처 품질에 좌우됩니다. 저장 전 확인 화면에서 반드시 검토하세요.
- 신용카드 결제는 연결한 계정에서 바로 차감되는 방식으로 처리합니다(카드 대금 부채는 별도 관리하지 않음).
- iOS는 장기간 미사용 시 웹 저장소를 정리할 수 있습니다 → 정기 백업 권장.
